# ADR-001: Use Domain-Specific Triage for Trades

## Status

Accepted

## Context

Generic customer support triage does not capture the urgency, safety risks, or routing needs of trade service businesses.

Electricians, plumbers, and roofers each have different emergency triggers, quote workflows, and dispatch requirements.

## Decision

The system will use trade-specific classification categories for electrical, plumbing, and roofing requests.

## Consequences

This improves routing accuracy and portfolio relevance. It also requires maintaining domain-specific rules and examples as the system expands.
