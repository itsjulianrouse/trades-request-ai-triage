# ADR-002: Require Human Oversight for Dispatch Decisions

## Status

Accepted

## Context

AI can help classify and prioritize requests, but emergency trades work involves safety, liability, property damage, and customer trust.

## Decision

The system will recommend routing but require human review for high-risk, emergency, low-confidence, or ambiguous requests.

## Consequences

This reduces automation risk and keeps dispatchers accountable. It may add manual review time, but it supports safer operations.
